# Figtree for social previews

Static Figtree SemiBold (600), downloaded on 2026-10-21 from the Google Fonts
CSS endpoint `https://fonts.googleapis.com/css2?family=Figtree:wght@600`.
The static TrueType format is required by the social-image renderer; the variable
font does not render reliably there. License: SIL Open Font License, see `OFL.txt`.
